# extreme_weather_workforces
This project analyzes how extreme weather events impact workforces across the United States. Impacts to workforce will be quantified in different ways such as unemployment, injury rates, hires, turnover, and number of commuters.

# Research Question
How long does it take for workforces to rebound after a weather disaster? Are specific types of people more impacted than others? Are there certain weather events that cause more damage than others?

# Data
My extreme weather data comes from NOAA's Storm Events Database. The data starts in 1996.
